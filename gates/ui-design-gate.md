# Gate: UI Design

**Entry criteria:** IA gate passed and user authorized UI Design.  
**Exit criteria:** UI states are annotated and traceable; accessibility review is completed or its limitations are explicitly blocking; constrained content has approval/source status.  
**Evidence required:** UI specifications/prototypes, annotations, accessibility review, trace map.  
**Explicit approval required:** User approval to begin Usability Testing.  
**Failure rule:** Untested/unaddressed required states or unsupported claims block testing.
