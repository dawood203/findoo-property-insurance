# User Problem Statements

**Evidence status:** BRD-derived problem statements; not direct user-research quotes or validated need statements.

| User group | Problem statement | Supporting evidence |
|---|---|---|
| Residential policy shopper | Needs to understand intended protection and material choices without unexplained data requests or unsupported promises, because application complexity and affordability concerns can lead to abandonment or inadequate cover. | P-01, P-04; BRD-001–BRD-010 |
| Active claimant | Needs to begin and progress a claim safely, submit available evidence, understand status/ownership/next action and reach support without restarting, because a multi-step opaque claim process causes stress, delay, distrust and repeat contact. | P-02, P-03; BRD-013–BRD-023 |
| Existing policyholder | Needs secure access to policy details and approved support/servicing routes, because customers need help managing cover and resolving issues over time. | BRD §4; BRD-011, BRD-021–BRD-023 |
| Support/claims operations user | Needs authorized concise case context for reliable handoff, because repeated information and inadequate support contribute to unresolved issues and lower confidence. | P-03; BRD §4; BRD-022 |
