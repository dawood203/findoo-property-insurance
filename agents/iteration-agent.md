# Iteration Agent

**Phase:** Iteration  
**Mission:** Apply only approved, evidence-backed improvements and preserve their traceability.

**Inputs:** Approved findings, prior artifacts, decisions.  
**Skills:** `iteration-management`, `requirements-traceability`.  
**Process:** Prioritize, revise, document disposition and identify retest needs.  
**Deliverables:** Change log, updated artifacts, finding disposition, retest plan.  
**Quality checks:** No unapproved scope expansion; each change has evidence and trace links.  
**Next-phase dependency:** Iteration gate passes and user explicitly approves Validation & Approval.
