# Information Architecture — User Flows

**Evidence status:** BRD-implied flows. Stage names, owners, update windows, verification method and support commitments remain unconfirmed unless the BRD states otherwise.

## Flow A — Obtain understandable cover

`IA-01 → IA-02 → IA-03 → IA-04 → IA-05 → IA-06 → approved purchase handoff`

| Step | Required information / action | Exit / alternate | Traceability |
|---|---|---|---|
| Need and coverage explanation | Approved explanation, exclusions, deductible and full wording. | Help, exit, start application. | BRD-001 |
| Application | Required underwriting information, reasons for sensitive/unfamiliar requests, permitted prefill/source/correction, accessible errors. | Save/resume, IA-20, support. | BRD-002–BRD-005 |
| Review / underwriting | Present manual route without unsupported instant decision. | Save, help, verified options if available. | BRD-006 |
| Compare and choose | Show verified eligible options and approved disclosure; explain choice consequences. | Approved purchase handoff, help, return. | BRD-007–BRD-012 |

## Flow B — Start and progress a claim

`IA-07 → IA-10 → IA-11 → IA-12 → IA-13 → IA-14 ⇄ IA-15 → IA-16`

| Step | Required information / action | Exit / alternate | Traceability |
|---|---|---|---|
| Verify and start | Authenticated access or approved alternate verification; discoverable start path. | Verification recovery, support. | BRD-013 |
| Safety | Emergency guidance distinct from insurance support. | Emergency-services exit, continue claim. | BRD-014 |
| Report / evidence | Incident, safety details, declarations, available evidence and labels for mandatory/optional/later. | Save/resume, IA-20, support. | BRD-015–BRD-016 |
| Confirm | Reference, stage, next action, responsible party and update window when known. | Claim status, support. | BRD-017 |
| Progress | Upload evidence, answer requests, read time-stamped communications and material updates. | IA-15, support, recovery. | BRD-018, BRD-020 |
| Decision | Approved explanation, payment status when available and escalation/appeal route. | Escalation, support, timeline. | BRD-019 |

## Flow C — Resolve a support issue

`task context → IA-17 → IA-18 or channel handoff → IA-19 → return or escalation`

| Step | Required information / action | Exit / alternate | Traceability |
|---|---|---|---|
| Find help | Approved channels, hours, accommodations and escalation route. | Channel handoff, callback/case. | BRD-021 |
| Preserve context | Present authorized quote/claim reference or summary. | Continue task, support handoff. | BRD-022 |
| Unavailable real-time support | Offer callback or case submission. | Receipt/history, escalation if approved. | BRD-023 |
| Feedback | Offer feedback without blocking completion. | Return/end. | BRD-024 |
