# Gate: Define

**Entry criteria:** Research gate passed and user authorized Define.  
**Exit criteria:** Problem/scope/outcome proposal is traceable; out-of-scope and open decisions recorded; no unapproved targets/rules represented as facts.  
**Evidence required:** Definition brief, scope record, measure proposal, decision-log updates.  
**Explicit approval required:** User approval to begin Information Architecture.  
**Failure rule:** Ambiguous or unsupported scope blocks Information Architecture.
