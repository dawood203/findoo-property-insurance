# Skill: BRD Analysis

**Objective:** Extract documented business evidence without expanding it into invented requirements.

**Required inputs:** BRD source, approved clarifications, previous traceability matrix if present.

**Execution steps:**

1. Read the complete source and record version/date.
2. Separate facts, requirements, constraints, assumptions, dependencies, risks and open questions.
3. Preserve original section/requirement references.
4. Record contradictions only where statements actually conflict; label tensions separately.

**Output format:** Markdown analysis with source citation, evidence convention, numbered analysis sections and open-question list.

**Quality checklist:** Complete source review; no inferred facts labeled as facts; unknowns are explicit; language does not imply approval.

**Restrictions:** Do not create UI designs, policy language, market facts, legal conclusions or requirements absent from the source.
