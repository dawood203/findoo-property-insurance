# Gate: UX Validation & Approval

**Entry criteria:** Iteration gate passed and user authorized validation.  
**Exit criteria:** Validation pack identifies requirement coverage, residual risk, all gate evidence and status of DPO/EO external approvals; Box status is evidenced or `Not evidenced`.  
**Evidence required:** Validation report, final traceability, approval pack, review presentation, external-approval log.  
**Explicit approval required:** User acceptance of the validation outcome; any release/publication requires separate explicit authorization.  
**Failure rule:** Missing evidence, unresolved required approval, or a rejected external approval blocks any release/readiness claim.
