# Design System Direction — Findoo Property Insurance

**Source:** Explicit user instruction, 16 October 2026.  
**Primary design system:** Google Material Design 3 (M3).  
**Required skill:** `material-design-3`.  
**Accessibility target:** WCAG 2.2 AA.

## Responsibilities

Analyze approved UI requirements; apply M3 guidelines, color roles, typography and components; create responsive insurance layouts; maintain consistency and document component specifications.

## Requested insurance components

- Property Information Form
- Coverage Selection Card
- Premium Summary
- Quote Comparison
- Policy Review
- Confirmation Screen

## Required validation

Verify M3 compliance, accessibility, responsive behavior and requirements traceability before completing UI Design, then submit the design for UX validation through the existing phase gates.

## Evidence status

This instruction supplies the design-system selection and accessibility target. It does not supply a brand theme, rendered screens, completed accessibility tests, responsive test results, operational rules or retest evidence. Existing approvals and Gate 06 blockers are not automatically cleared.
