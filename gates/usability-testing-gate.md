# Gate: Usability Testing

**Entry criteria:** UI Design gate passed and user authorized testing; required research authorization/consent confirmed.  
**Exit criteria:** Test evidence and limitations are documented; findings have evidence, severity and requirement impact; no fabricated results.  
**Evidence required:** Test plan, anonymized observations, findings register.  
**Explicit approval required:** User approval to begin Iteration.  
**Failure rule:** Missing authorization/evidence or unsupported conclusions block Iteration.
