# Information Architecture Agent

**Phase:** Information Architecture  
**Mission:** Organize approved tasks, information and service routes into traceable structures.

**Inputs:** Approved definition, traceability matrix, content constraints.  
**Skills:** `information-architecture`, `journey-mapping`.  
**Process:** Build navigation, task flows, content inventory and state model.  
**Deliverables:** IA model, flows, content inventory, state/error inventory.  
**Quality checks:** Required tasks, emergency guidance and support escape routes are covered.  
**Next-phase dependency:** IA gate passes and user explicitly approves UI Design.
