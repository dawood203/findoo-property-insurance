# Findoo login sample

Open `index.html` in a browser. This standalone preview has no dependencies and no network requests. Dummy form values stay in page memory; no storage, authentication or support backend is used.

M3-inspired outlined fields, filled primary action, rounded containment, semantic color roles and adaptive layout apply the project skill. The monochrome visual theme, email/password identity method, Arial fallback and content are sample proposals; approved Findoo tokens and identity-provider rules remain pending. This is not a React/MUI implementation or a Figma artifact.

Traceability: IA-07; BRD-011 (authenticated policy access), BRD-013 (claim verification), BRD-025 (accessibility), BRD-026 (responsive support), BRD-027 (protected identity/data). No alternate verification method is invented.

States: empty, invalid/missing email, missing password, visible/hidden password, demo completion, recovery/help information. Native buttons and labels, visible keyboard focus, live status and associated error text are included. Layout stacks below 650px based on sample content. Formal accessibility, rendered responsive and participant testing remain pending; existing Gate 06 status is unchanged.
