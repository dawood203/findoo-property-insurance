# Gate: Information Architecture

**Entry criteria:** Define gate passed and user authorized IA.  
**Exit criteria:** Navigation, priority flows, content and state/error inventory are traceable; support/emergency paths covered where required.  
**Evidence required:** IA model, journey flows, content/state inventory, trace map.  
**Explicit approval required:** User approval to begin UI Design.  
**Failure rule:** Missing required flow, recovery state or trace links blocks UI Design.
